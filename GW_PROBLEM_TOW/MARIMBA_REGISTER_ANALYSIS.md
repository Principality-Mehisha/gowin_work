# 马林巴低音微调与高音音色分析

日期：2026-10-22。当前核心为 B2–F5 的 31 音实时马林巴。本文基于本地 Iowa yarn mallet PCM、拟合报告、RTL 和新导出的实际 RTL 采样；不以 Apple 参考铃声作为真实木条参数。

## 本次修改与验证

`tools/fit_marimba_params.py` 的最大低音补偿从 +4 dB 调至 +3 dB，保留按半音位置的余弦过渡，到 C4 为 0 dB。B2 加权 RMS 从 1589.36 降为 1410.89，实测 -1.035 dB（幅度约降低 11.2%）；C3 实测 -1.005 dB，F3 约 -0.563 dB，B3 约 -0.013 dB。整数包络截断会使实际变化与理想增益略有差别，因此对完整链重新标定，而非直接缩放 ROM 整数。

只改变 B2–B3 的模态/起音增益；所有音符的频率字、衰减系数保持一致，C4–F5 参数及输出逐点不变。高音分析未引入高音音色修改。

## 为什么低音饱满、高音更单薄

### 1. 当前 mf 源录音的高音本来就更纯、更短

| 音符 | 拟合基音时间常数 τ | 当前有效模态数 | mf 第二模态相对基音 |
| --- | ---: | ---: | ---: |
| B2 | 0.393 s | 4 | -15.0 dB |
| C4 | 0.207 s | 3 | -30.7 dB |
| A4 | 0.133 s | 1 | 被关闭：低于 -52 dB |
| C5 | 0.146 s | 3 | -29.6 dB |
| F5 | 0.106 s | 2 | -42.9 dB |

τ 表示指数幅度降到初始值 1/e 所需时间，不是尾音完全结束时间。B2 第三模态相对基音仍约 -8.3 dB，提供明显的短暂高频层次；A4 的输出则几乎为基音加短槌击噪声。

对源 PCM 起音前 100 ms 加 Hann 窗，在 80 Hz–输出奈奎斯特频率内统计、排除基频周围 max(35 Hz, 8% f0) 的宽频带后，剩余频谱能量占比为 B2 约 25.33%、A4 约 0.037%、F5 约 0.172%。该指标包含噪声与瞬态，不能直接等同于高阶模态能量，但支持“当前 mf 高音源录音本身更纯”的判断。

因此，不能预设高音一定要复制低音的四个强模态，也不能把高音简单变响就视为增加饱满度。

### 2. 合成尾音比源录音进一步缩短

以下为 300–500 ms RMS 相对 0–100 ms RMS 的比例，越负表示尾段相对起音越弱：

| 音符 | 源 PCM | RTL |
| --- | ---: | ---: |
| B2 | -0.15 dB | -11.55 dB |
| C4 | -9.20 dB | -27.75 dB |
| A4 | -19.49 dB | -38.23 dB |
| C5 | -18.69 dB | -30.13 dB |
| F5 | -26.01 dB | -44.10 dB |

这是整段能量的对照，不能把差值全部归因于一个模态或量化。

已确认的机制是 `marimba_synth.v` 每个采样执行 `level_next = floor(level * decay / 32768)`。16 位幅度状态没有保留乘积小数，低电平时每帧至少下降 1，弱模态和尾音会提前消失。A4 理想拟合包络降 20 dB 约需 0.306 s，当前整数包络约 0.249 s，基音幅度状态约在 0.331 s 归零；F5 对应约 0.244 s、0.211 s、0.325 s。

这一损失同样存在于低音，不能称为高音专属缺陷。当前低音仍有较强的模态层次和较长衰减，高音缺少这些余量，提前归零会进一步削弱余韵。单指数包络也无法完整表达源声音的起音增长、双阶段衰减和拍动；表中差异需要结合这些模型误差理解。

### 3. 固定琴体滤波不是逐音反演的共鸣模型

`marimba_body_filter.v` 对所有音符使用同一组约 385/727 Hz 的阻尼谐振器。这是额外染色，已纳入增益校准，但系数并非从每个音的残差中拟合。

线性频响在 B2 基频约 +4.52 dB、C4 约 +4.70 dB、A4 约 +2.46 dB、C5 约 +0.65 dB、F5 约 -0.71 dB。逐音校准会抵消部分总电平差，因此不能直接把这些数值当作最终音量差；它们表明不同音区受到了不同的频谱染色。真实马林巴各木条有对应的共鸣管，当前固定滤波器不能代表整套逐音共鸣管。

参考 Yamaha 对共鸣管结构的说明：
https://www.yamaha.com/en/musical_instrument_guide/marimba/mechanism/mechanism002.html

### 4. 测量了 pp/mf/ff，但运行时只有 mf 参数

ROM 只使用 mf。现有力度把基音按力度缩放、高阶模态和噪声按近似二次曲线缩放，不会选择实测 pp/ff 的不同频谱与衰减。

例如 F5 第二模态相对基音：mf 约 -42.9 dB，ff 约 -13.9 dB；相差约 29 dB。A4 在 mf 的高阶模态全部被关闭，但 ff 第二模态仍可拟合到约 -34.4 dB。已有 mf 模态为零时，力度缩放无法恢复这些强击细节。这是当前参数反演利用不足的一处明确证据；ff 选峰仍需在引入前单独验证。

### 5. 采样带宽和模型假设是次级限制

当前输出约 16.276 kHz，奈奎斯特约 8.138 kHz，部分高音的更高模态会被正确关闭。A4 的第二模态只有约 1.77 kHz，却因太弱而关闭，因此带宽不是当前高音单薄的唯一原因，单纯提高采样率不会恢复它。

搜索区间固定为约 1、4、10、18 倍基频，每个模态只保留一个频率、增益和衰减常数；不保存源相位或起音增长。18 ms 噪声虽然由 1.5–7.5 kHz 残差估计增益，但 RTL 使用的是宽带伪随机噪声，未拟合残差频谱。近频模态、双阶段包络、残差色彩和左右声道差异都可能因此丢失。目前证据不足以认定某个遗漏谱峰就是“空灵感”的单一来源。

## 后续改进顺序

1. **优先保留包络小数精度**：扩展模态幅度状态或保存乘积余数，继续用较宽中间结果计算，避免低电平每帧丢失小数。随后重新标定增益，检查尾音和复音计算预算。不要仅靠提高 decay 系数补偿截断。
2. **提高反演模型对源录音的解释能力**：区分起音和尾音，对基音尝试双阶段衰减；在四个算力槽内按实测残差挑选模态，验证比固定比例搜索是否更好。不要把噪声或泄漏峰当成新模态。
3. **使用已测 pp/mf/ff**：先对高音强击模态重新核查，再做逐音的参数插值或分层选择。分别对齐各力度的响度，避免把音量跳变误当音色变化。
4. **有证据后再改共鸣和起音**：先比较绕过滤波器的结果，再从残差拟合随音区变化的共鸣/噪声参数，避免重复叠加源 PCM 中已经存在的共鸣。

若目标是让高音具有超出当前 mf 原录音的长余韵或空间感，需要作为明确的音色设计分支，用独立参数控制并做试听选择；这不能宣称是对原录音的忠实反演。

复现分析：先运行 `sim/tb_marimba_wav.sv` 导出实际 RTL，再执行 `python tools/analyze_marimba_registers.py`。脚本断言 504556 点匹配、低音目标曲线、全部音高/衰减系数不变及 C4 以上逐点一致。依赖优先从 `output/marimba_tools` 读取。
