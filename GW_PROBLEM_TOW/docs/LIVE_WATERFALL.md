# 实时钢琴瀑布流

模式0观察实际演奏：压力键盘、串口屏钢琴单音试听、SD编号钢琴播放共用同一通路。
命令仍是CMD=0x50、参数0，原view_waterfall_release.txt按钮无需修改。

## 显示行为

- 按下后在下一次60 Hz换帧时从顶部出现音块，随后每帧向下滚动4像素。
- 持续按住形成连续长条；松开后不再延长，已有长条继续下落。显示区域保留最近180帧，约3秒。
- 下方琴键跟随当前音符亮灭；音块约3秒后到达下方，不再次触发声音或亮键。
- 和弦并行显示，覆盖88键；帧间短按至少显示一格4像素。同一键在一个视频帧内的多次触发会合并。
- 压力力度更新不重新触发或切断长条。显示的是按键门控时长，不是ADSR释放尾音或频谱识别结果。
- 普通松键、试听尾音结束和SD自然结束后保留轨迹并继续滚出。
- 停止、换SD曲目、从SD切到试听、切换乐器、错误及KEY2复位清屏；马林巴不进入钢琴瀑布流。
- 显示模式0/1/2之间切换不改变演奏，也不清除瀑布流最近轨迹。

## 数据通路

instrument_system在钢琴合成器实际接受事件时维护88位当前按键状态。
只观察event_valid/event_ready握手，不读取固定乐谱ROM，也不向音频路径施加背压。
压力、试听、SD的事件选择仍由原有控制逻辑负责，SD无需改格式或重传。

playback_video_cdc扩展原有请求/确认快照，将当前按键、帧间按键活动、清屏标志一起原子跨域。
帧间活动用OR锁存捕获很短的音符；当前按键单独传输，避免已松开的短音仍亮键。
单周期停止/换曲命令锁存到下一次快照，不会因短于视频帧而遗漏清屏。
数据保存在mailbox直到确认，沿用已有mailbox跨域约束，不增加SD或音频时钟域。

piano_live_roll在108 MHz像素域保存180×88位循环历史。历史RAM不做逐项复位，
用有效行数使旧内容失效；每次垂直消隐更新一行，活动像素期间只读取。
同步RAM读和键位列查表对齐，保持现有五拍RGB/同步信号流水。
每列按琴键音高着色，沿用既有键盘和配色。88键直接以位图保存，没有旧的64音块槽位限制。

piano_video固定选择REALTIME=1。旧固定谱面分支仅用于历史测试，其ROM不驱动当前生产画面。


单周期清屏、停止后新按键、显示模式切换及传输中复位。

UART试听、真实SD播放和真实压力ADC集成分别比对瀑布流亮键与钢琴合成器门控状态，
覆盖力度更新、尾音、曲目切换及马林巴隔离。证据在output/live_waterfall/verification.json。
