# 压力钢琴与马林巴

参考工程为`D:\GW_basic_KEYBOARD`。保留现有PN/MB槽位、蓝牙v2和串口屏v1，
不合入参考工程的旧FAT播放分支，也不替换现有马林巴。
压力键可演奏钢琴或马林巴，由原串口屏乐器命令选择。

## 运行方式

- 顶层`PRESSURE_ENABLE=1`默认启用压力输入，上电空闲时可直接演奏钢琴。
- 原`SD_SCORE_ENABLE=0`仍表示上电不自动播放SD，不是关闭SD功能。
- 串口屏选PN/MB自动播放时压力事件暂停；SD结束或停止后恢复。
- CMD=0x53开启跟弹后，PN期间开放压力演奏并自动映射提示音高组；仅最高起奏音组参与过关，见[KEY_GUIDE.md](KEY_GUIDE.md)。
- 串口屏单音试听优先，试听及尾音窗口内暂停压力事件。
- 选马林巴后使用其前三组音域，选钢琴后恢复原钢琴分组；切换时先清音，仍按住的键需松开重按。
- 停止、换曲、试听及切乐器都会清除旧队列和声部；仍按住的已确认按键必须松开再按，不重放旧事件。
- ADC、滤波及校准始终运行，切换模式不会重新标定基线。
- KEY2复位所有状态并重新校准，校准期间松开全部16键。
- 蓝牙仍只上传，上传与SD播放仍由操作者错开；压力演奏不访问SD。

屏幕原命令无需改变。`page0.n0.val=4`现在也包括压力手动演奏及其尾音；
音名文本仍表示串口屏选中的试听音，不表示16键中某一键。
压力队列溢出会锁存错误`0x61`（屏幕十进制97）、清音且暂停演奏。
停止、重新选曲/试听/乐器或KEY2可清除，未松开的键不会自动重触发。
八路GPIO LED已替换为长按进度条，原SD/校准/播放/错误灯用途全部移除，详见下一节。
选曲准入已与显示状态解耦，使用已有SD占用寄存器；首次读取目录时可从正在发声的压力钢琴转入SD。

## 八灯长按进度

`LEDs[7:0]`低电平点亮，LED0开始依次累计点亮，每档约0.5秒：

| LED | 阈值 | 球位 |
| --- | --- | --- |
| LEDs[0] | 0.5 s | AB20 |
| LEDs[1] | 1.0 s | AA19 |
| LEDs[2] | 1.5 s | AA21 |
| LEDs[3] | 2.0 s | AA20 |
| LEDs[4] | 2.5 s | AB22 |
| LEDs[5] | 3.0 s | AB21 |
| LEDs[6] | 3.5 s | Y22 |
| LEDs[7] | 4.0 s | Y21 |

计时从压力算法确认按下时开始，不是从首次模拟波动开始。
多键时取当前有效按住键中最长的时间；不同键、不同次按压不累加。
最长键松开后显示剩余键中的最长时间，全部确认松开立即全灭，不显示音源释放尾音。
SD加载/自动播放、串口屏试听及其尾音、压力故障、复位和校准期间全灭；PN跟弹有效按键时正常显示。
压力马林巴也显示有效按键的按压时长；声音自然衰减后，仍按住的键可以继续点灯，灯不表示声音仍在持续。
切回压力模式时仍按住的键不会点灯，需先松开再按，与声音准入规则一致。
超过4秒保持八灯全亮，不闪烁、不循环。
独立的`LED_indicator_static`静态彩灯不受影响。

实现复用逐键held_frames；默认每键计数器在8336帧封顶，仅需14位。
以16键阈值标志并行合并得到最长时长，不增加八套独立计时器或16级最大值比较链。
顶层`PRESSURE_LONG_HOLD_FRAMES`默认按50 MHz和扫描周期计算半秒所需帧数，
在当前1500周期/通道时为1042，实际每档0.50016 s，八档约4.00128 s。
这是按扫描帧量化的近似时间。该参数可用于仿真加速，不应将加速值用于实际硬件。
GPIO端口在顶层、播放器和系统层均为8位，避免中间4位端口造成高位错误输出。
错误仍通过串口屏错误字段反馈，不再由GPIO LED指示。

## 接线

新增引脚与参考工程一致，全部为3.3 V接口。不要将5 V输出直接接FPGA。
引脚表为FPGA球位，不是排针脚号。

| 端口 | 球位 |
| --- | --- |
| ADC_DATA[11:0]，从11到0 | E14 C15 B13 A14 B16 A16 A20 A21 E13 C14 C13 A13 |
| S[3:0]，从3到0 | F13 E16 D14 A18 |
| S_EN，低有效 | D17 |
| CLK_500kHz | B15 |
| pitch_group[6:0]，从6到0 | F16 F15 D20 E19 C18 C17 A19 |

分组输入加内部下拉；全0默认第一组，多位置1时最低位置优先。
以下钢琴分组保持不变：
bit0～bit6分别选基音索引0、16、32、48、64、80、96；
物理键k对应`min(基音+k,87)`，索引0=A0、87=C8。
高音越界夹到C8，同音高多键取最大力度，最后一个持有者松开才发note-off。
切分组不改变已经按下的音高，松键事件仍匹配原来的音。
初测可将bit2置1，得到索引32～47；默认第一组包含低频音，不要以小扬声器听不清低音判断采样失败。

## 马林巴演奏

原CMD=0x44选择马林巴，CMD=0x43选择钢琴；CMD=0x50的频谱/波形按钮两种乐器共用。
马林巴按确认按下时的压力确定本次敲击力度，此后自然衰减。
按住和继续改变压力不重敲、不改变本次敲击响度；松开不截断声音，松开重按可再次敲击。
沿用现有马林巴模态、噪声、琴体滤波和公共限幅器，没有复制音源或FFT。

| 输入选择 | MIDI | 16键音域 |
| --- | --- | --- |
| 全0或pitch_group[0] | 36～51 | C2～D#3 |
| pitch_group[1] | 52～67 | E3～G4 |
| pitch_group[2] | 68～83 | G#4～B5 |
| pitch_group[3]～[6] | 无 | 不产生新音符 |

多位同时选择仍按最低位优先。切组不改变已经按下的音符或其松开匹配；
选择无效组不会切断先前有效敲击的尾音。无效组选中时按下的键，即使随后切回有效组，也需松开重新按下。
无效按压不进入事件队列，也不点亮长按灯。

频谱/波形跟随实际DAC样本，支持两种乐器的压力、串口屏试听及PN/MB播放。
马林巴分析不依赖按键是否松开；150 MHz音频域下模态/噪声结束后再保留384音频帧（约7.86 ms）的滤波清尾窗口。
切乐器、停止及复位清除旧分析代次，画面使用AUDIO标题，空闲提示WAITING FOR AUDIO。
钢琴实时瀑布流完全独立，马林巴没有瀑布流或亮键数据。

## 采样与力度

通道选择按用户提供的`对应关系.xlsx`的`Sheet1!A2:A17`从上到下排列，
每个数减一后输出为`S/select`：
`12,8,7,3,2,6,9,13,14,10,5,1,0,4,11,15`，末路后回到12。
`sample_key`仍按表格行序输出0～15，表示逻辑琴键，而非物理MUX地址。
复位从逻辑键0、物理地址12开始。专项验证入口为`sim/run_pressure_scan.ps1`。

与参考工程相同：50 MHz系统时钟、500 kHz ADC时钟、每路30 us、16路一轮480 us。
音频合成现为独立150 MHz域，通过官方双时钟FIFO接收压力事件；ADC扫描与长按阈值不倍频。
默认在通道切换后约29.8 us取样；两级输入寄存器不保证12位总线自动一致，
实际ADC的转换边沿、流水线延迟、tCO及模拟通道稳定时间仍需上板确认。
没有虚构ADC输入延时或新增整条ADC路径的false path。
分组开关仅异步输入到第一级同步寄存器设置例外，其余内部逻辑仍按50 MHz检查。
未降低系统、像素或串行时钟目标。

每键启动平均32次样本建立基线，约15.36 ms；按压假定ADC值下降。
Q12.4一阶滤波，下降64码连续3帧确认按下，下降不超过32码连续3帧确认松开。
沿用轻触增强、持续力度合并、32项边沿FIFO和独立同音高持有者跟踪。
力度更新不重启相位/ADSR/琴槌瞬态；每个音频帧增减一个Q0.8单位平滑到目标。
松键后冻结已应用力度，让释放尾音自然完成，后续压力更新不影响该尾音。
钢琴状态RAM在原低83位上增加8位已应用力度；既有调试低位偏移不变。
没有复制新音频ROM，也没有增加一套钢琴音源或限幅器。

## 验证与编译

```powershell
powershell -ExecutionPolicy Bypass -File sim/run_pressure.ps1
```

此入口仅做静态检查、夹具生成和ModelSim仿真，不运行Gowin综合/布局布线。
测试含12位力度全扫描、16键和弦、力度升降、尾音、全部分组组合、
共享C8、反压/溢出、真实顶层ADC/UART/SD/DAC接入、模式切换和KEY2。
tb_hold_progress分别用4帧加速档位和1042帧默认档位检查全部八个阈值、
封顶、多键最长时间、松键回落、轮流按键不累加、模式切换后重新按键及复位。
顶层测试检查8位低有效LED输出、所有模式熄灭条件，以及松键后即使声音仍有尾音也全灭。
另比较新旧力度模式下的常规事件PCM，并验证88音开启实时力度时的计算周期预算。
tb_play_admission主动改变反馈状态，验证其不影响冷启动选曲，同时检查SD占用保护、
已上传槽位切换、同曲不重启、试听抢占和复位。旧代码在此隔离测试中失败，修正后通过。
马林巴新增回归入口`sim/run_marimba_pressure.ps1`，覆盖48音映射、无效组、
敲击力度锁存、16键和弦、自然衰减、滤波尾音、真实DAC采样/FFT、显示换帧和两个完整RGB画面。
顶层`PRESSURE_ENABLE=0`可关闭压力功能用于对照；单独的`piano_score_player`默认仍为0以兼容原测试。

最终综合、布局布线和上板由用户执行。现有`.fs`不会由本次仿真更新，
不能当作已包含本功能的新位流；资源占用和物理时序尚待用户编译确认。
