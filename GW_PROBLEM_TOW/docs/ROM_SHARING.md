# 马林巴参数ROM与正弦表复用

## 本轮范围

只改动piano_synth、marimba_synth和instrument_voice_bank，新增sine_pair_rom。
音频仍为150 MHz、48828.125 Hz；控制仍50 MHz。
没有缩减88音钢琴/48音马林巴，没有改参数精度、插值、包络、限幅器或效果器。
SD布局、上传协议、屏幕指令、压力映射、LED、视频、引脚和SDC均保持不变。
蓝牙FIFO与效果缓存仍各自独立，上传期间的压力演奏行为也未改。

## 马林巴参数

原来每音一次读256位四模态参数，再从宽寄存器中选出当前模态；
起音参数在相同note_index地址读取，综合后与该宽表合并。
现在为一张256×64位、单同步读口的常量表：

| 地址 | 内容 |
| --- | --- |
| 0～191 | note_index×4+mode_index，完整64位模态参数 |
| 192～239 | 当前音符起音参数，低32位有效 |
| 240～255 | 零 |

NOTE_START预取模态0，MODE_COMMIT/ADVANCE预取下一模态。
MODE_LOAD消费模态3后，同拍预取起音参数；其值一直保持到NOISE_LOAD使用。
因此没有增加FSM状态或每样本计算周期，也没有把一份宽表变成四个并行读口。

原有marimba48.hex、marimba48_48828.hex和marimba_attack48.hex格式/内容完全保留。
initial_modes/initial_attacks只供初始化时重排，运行时仅mode_rom有读口。
用户综合后应确认这两个初始化数组没有被保留为额外硬件存储器。

## 正弦表

instrument_voice_bank中的shared_wave由两种互斥音色共用，
保留当前相位和相邻相位两个同步读口，地址255的下一项回到0，enable为0时保持输出。
钢琴沿用每拍读取；马林巴仍只在SINE_READ读取，消费者不再额外寄存一拍。
音色选择来自现有音频域配置，没有新增跨时钟信号。

两个音源新增EXTERNAL_SINE参数，银行内设为1，直接消费共享查表结果。
默认0供历史独立音源测试使用，此时各自例化同一个sine_pair_rom模块；
生产银行内不会再同时保留两套私有表。切音色仍由已有stop_all清除旧计算。
