# 淘晶驰串口屏接口

当前 `piano_score_player.UART_BAUD` 默认值为 115200，屏幕脚本及主机工具已与之对齐。原来使用 9600 的屏幕工程需同步设置波特率；按钮帧内容不变。

目标屏：TJC8048X270_011C。配置为 115200/8N1，无流控，3.3 V TTL。
当前有效约束为 `src/board/GW_PROBLEM_TOW.cst`：FPGA RX=B17 接屏幕 TX，FPGA TX=B18 接屏幕 RX，双方共地。
屏幕独立供电，按板卡原理图核对球位到连接器的映射；本文不沿用旧版本未经一致核对的 J8 脚号。

## 屏幕工程

保留 USART HMI 模板全局声明，在最终 `page 0` 之前设置：

```text
bauds=115200
recmod=0
bkcmd=0
page 0
```

在 `page0` 创建全局数字控件 `n0`～`n5`，在 `every` 创建全局文本控件 `tNote` 和 `tInstrument`。
`tInstrument` 显示当前虚拟试听乐器，使用包含“钢琴马林巴琴”的 GB2312 字库，文本容量至少 8 字节。
名称是协议的一部分。关闭按钮默认“发送组件 ID”，仅在触摸弹起事件发送一条 `printh`。
页面后初始化事件发送查询，保证屏幕进入页面后同步状态。
`screen/tjc_uart/` 提供可复制脚本；这些不是已编译的 HMI/TFT 屏幕工程。

## 命令帧

固定 10 字节，以下值均为十六进制：

```text
A5 5A 01 SEQ CMD P0 P1 P2 SUM 0D
SUM = (01 + SEQ + CMD + P0 + P1 + P2) & FF
```

SEQ 回显且不去重；固定按钮可用 00。除编号选曲0x12使用P1外，P1/P2必须为00。

| CMD | 功能 | P0 |
| --- | --- | --- |
| 01 | 查询状态 | 00 |
| 10 | 播放曲目 | 01 安卓、02 苹果、03 钢琴 |
| 11 | 停止并清音 | 00 |
| 12 | 编号曲目播放，P1=十进制1～100、P2=0 | 01钢琴PN、02马林巴MB |
| 40 | 选择当前试听乐器的上一个音 | 00 |
| 41 | 选择当前试听乐器的下一个音 | 00 |
| 42 | 播放当前试听音 | 00 |
| 43 | 切换试听乐器为钢琴，停止当前播放 | 00 |
| 44 | 切换试听乐器为马林巴琴，停止当前播放 | 00 |
| 50 | 切换钢琴HDMI显示，不改变播放 | 00瀑布流、01频谱、02波形 |

可直接复制的按钮命令：

```text
// 安卓
printh A5 5A 01 00 10 01 00 00 12 0D
// 苹果
printh A5 5A 01 00 10 02 00 00 13 0D
// 钢琴
printh A5 5A 01 00 10 03 00 00 14 0D
// 停止
printh A5 5A 01 00 11 00 00 00 12 0D
// 查询／页面后初始化
printh A5 5A 01 00 01 00 00 00 02 0D
```

同曲正在加载或播放时再次选择不会重启；换曲会清音并从头加载。
默认模式下自然结束返回手动试听，保留曲目编号；停止将曲目编号清零。
单音命令和操作见 [UART_THREE_KEYS.md](UART_THREE_KEYS.md)。

## 返回字段

FPGA 返回原生控件赋值（命令/数字为 ASCII，汉字为 GB2312），每条末尾为原始 `FF FF FF`，快照开头也发送三个 FF 清理半条指令。

| 返回控件 | 含义 |
| --- | --- |
| page0.n0.val | 0=手动/空闲，1=加载，2=播放，3=播放错误，4=单音试听 |
| page0.n1.val | 0=无选择，旧三首1/2/3，PN编号曲目4～103，MB编号曲目104～203 |
| page0.n2.val | 错误码，以十进制显示 |
| page0.n3.val | 0=接受，1=参数错，2=不支持；主动快照 3=反馈溢出 |
| page0.n4.val | 请求 SEQ；主动快照为 0 |
| page0.n5.val | 请求 CMD；主动快照为 129（0x81） |
| every.tNote.txt | FPGA 当前选中音名，如 C#4 |
| every.tInstrument.txt | 虚拟试听键选择的乐器：钢琴或马林巴琴 |

数字为十进制文本，音名使用 ASCII `#`，乐器名使用 GB2312。上电、复位、状态或选择变化会主动回传；查询也会回传。同一快照锁存状态、音符和乐器。
返回“命令接受”并不代表 SD 加载成功，应继续观察加载、播放或错误状态。

| n2 错误码（十六进制） | 含义 |
| --- | --- |
| 1x | SD 错误，低四位为 SD 模块错误码 |
| 2x | FAT 错误，24 为文件不存在 |
| 3x | 乐谱错误，31 为文件头/格式错误 |
| 40 | 事件调度错误 |
| 50 | 合成计算超时 |
| 60 | UART 反馈队列溢出 |

反馈 FIFO 深度 16，控制器预留槽位以等待命令结果入队。
过载时无法排队的普通请求被丢弃，停止仍执行；溢出标志保持到 KEY2 复位。
建议按钮间隔至少 300 ms，查询约每秒一次。半帧 20 ms 没有新字节会丢弃。
校验、版本、帧尾或停止位错误的帧不执行也不回复；有效但不支持的命令返回结果 2。

主机示例：`powershell -File tools/send_uart_command.ps1 -Command InstrumentMarimba` 仅打印帧；`InstrumentPiano` 切回钢琴。原 `Piano` 命令仍代表 SD 第三首曲目。显式指定 `-Port COMx` 才访问串口，默认 115200，`-BaudRate 9600` 可匹配其他编译配置。
验证：`powershell -ExecutionPolicy Bypass -File sim/run_uart.ps1`。

钢琴三种显示的完整按钮指令和分析范围见 [PIANO_ANALYSIS.md](PIANO_ANALYSIS.md)。

编号曲目及200个按钮脚本见 [蓝牙上传与编号播放](BLUETOOTH_UPLOAD.md)。
