# 钢琴与马林巴逐音试听

三个虚拟试听按钮分别发送十六进制命令40（上一个音）、41（下一个音）、42（播放）；两个音色按钮发送43（钢琴）、44（马林巴）。完整帧格式见UART_SCREEN.md，可复制的事件脚本在screen/tjc_uart/。

上电或KEY2复位后选择钢琴A0，马林巴独立初始选择C2。钢琴覆盖A0～C8共88音，马林巴覆盖C2～B5共48音；到达两端后循环。两种乐器分别记忆选择。

选音不发声，也不改变正在发声的音高。播放锁存当前选择并发出力度192的note-on，约0.5秒后note-off，保留约1秒尾音窗口后清音。重按播放重新触发；切换或重选乐器会清音。选曲或停止会中断单音，单音播放或切换乐器会停止SD曲目。

每次反馈由FPGA原子快照生成，六个数字字段后依次发送every.tNote.txt和every.tInstrument.txt。音名使用ASCII升号#，乐器名采用GB2312：钢琴为B8 D6 C7 D9，马林巴琴为C2 ED C1 D6 B0 CD C7 D9。每条命令末尾是原始FF FF FF，屏幕使用recmod=0。

板载KEY0、KEY1不参与控制。旧0x45命令返回“不支持”，选曲4返回“参数错误”，两者均不改变乐器、选择或播放状态。单音试听不需要SD卡。

回归入口sim/run_uart.ps1或sim/run_structure.ps1，覆盖88/48音映射、循环、独立记忆、反压、自动释放、切换、屏幕反馈和无效命令。
