# CLARINET.BIN — Chopin Nocturne Op.9 No.2

Composer: Frédéric Chopin. Source MIDI/engraving: Renato Biolcati Rinaldi /
Mutopia Project, Mutopia-2014/12/18-1590.

Source: https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=1590

License for this arrangement and its BIN, MIDI, note CSV and audio preview:
Creative Commons Attribution-ShareAlike 3.0 Unported:
https://creativecommons.org/licenses/by-sa/3.0/

Changes: extract the highest sounding upper-staff line; omit piano left hand
and lower chord tones; transpose the complete melody down one octave; convert
timing to millisecond C45S note events for the FPGA real-time clarinet synth.
The key remains E-flat major. Arrangement tool: `tools/make_clarinet_nocturne.py`.
See `CLARINET.json` for input/output hashes, exact statistics and source credit.
