# Piano_88：真实钢琴 PCM 采样，按键切换全部 88 音

适用本仓库的 Tang Mega 60K 核心板 + NEO Dock 底板，
器件 `GW5AT-LV60PG484AC1/I0`（GW5AT-60B）。
使用底板 PT8211 DAC 和功放输出，左右声道播放相同音调。

## 操作

上电或复位后保持静音，不会自动跳音。

| 按键 | FPGA 管脚 | 功能 |
| --- | --- | --- |
| KEY1 | AB13 | 第一次按下播放 A0；以后每按一次升一个半音 |
| KEY0 | AA13 | 暂停 / 继续当前音；尚未选择音符时无动作 |
| KEY2 | Y12 | 复位到静音；下一次 KEY1 再从 A0 开始 |

按键低电平有效。KEY0、KEY1 经两级同步和 20 ms 消抖，
长按只产生一次动作，松开并再次按下才切换。
按 KEY1 时会恢复播放，因此暂停后也能直接切到下一音。
同时按 KEY0、KEY1 时，KEY1 优先。

第 1 次：A0（27.5 Hz）；第 2 次：A#0；第 3 次：B0；
第 4 次：C1；第 49 次：A4（440 Hz）；第 88 次：C8（约 4186 Hz）；
第 89 次回到 A0。全部音名和频率见 [NOTES.md](NOTES.md)。

参照 `Croatian_Rhapsody_PCM` 的架构，电脑端预处理钢琴录音，
FPGA 从外置 HEX 初始化的片上 ROM 读取 8-bit μ-law 数据，
解码为 16-bit PCM 后发送给 PT8211。
使用 15 个真实钢琴录音音区覆盖 88 音，不再使用正弦谐波振荡器。
每次切换从录音的击弦起音开始播放一遍，约 0.79–1.12 秒后结束，
末尾平滑淡出，随后持续发送精确的零值 PCM。
不循环录音尾部，避免主音结束后持续播放录音底噪和循环接缝杂音。
音符结束后仍保留当前选择，下一次 KEY1 播放下一音；
KEY0 关闭后再开启会从头重播当前音。
低音 A0 的实际响度取决于外接耳机或音箱的低频响应。
音源、许可和处理说明见 [assets/ATTRIBUTION.md](assets/ATTRIBUTION.md)。

电脑端可试听 `output/piano_88_preview.wav`（88 音顺序预览），
或 `output/piano_A4_rtl.wav`（由实际 RTL 仿真输出导出的 A4）。

## 接线与时序

管脚沿用已存在的 I2S_1 工程；按键所在 Bank 9 使用 LVCMOS15。

| 信号 | 管脚 | 说明 |
| --- | --- | --- |
| sys_clk | V22 | 板载 50 MHz，LVCMOS33 |
| HP_BCK | Y17 | 520.833 kHz 音频位时钟 |
| HP_WS | AB17 | 0 为右声道，1 为左声道 |
| HP_DIN | AA16 | 16 位有符号 PCM，MSB 先发 |
| PA_EN | AB16 | 低电平使能功放 |

连接底板音频输出到耳机或音箱即可，不需要外接蜂鸣器。
PT8211 使用 16 位 LSBJ / 右对齐格式，DIN、WS 在 BCK 下降沿更新。
位时钟 48 分频，采样率与参考 PCM 工程相同：
`50 MHz / 3072 = 16276.041667 Hz`；
配置后约 1.31 ms 上电复位，复位释放后约 50 ms 开启功放。
启动期间 PCM 为零；启动期间的按键选择会保留，启动完成后播放所选音。

音源为 C1、F#1、C2、F#2……C7、F#7、C8，共 15 个音区。
每区保存 15360 个样本，共 230400 字节有效数据；
ROM 声明深度为 262144，剩余数据填 μ-law 静音码 `FF`。
为每个音选最近的录音音区，使用 Q16.16 地址步进转调；
一个同步 ROM 端口分时读取相邻样本，解码后做线性插值，
避免复制整份 ROM。录音自身的调律和钢琴弦非谐性会影响实际频谱，
文档中的频率为 A4 = 440 Hz 的十二平均律名义音高。
预处理包含单声道转换、抗混叠低通、重采样、起音渐入，
以及最后 4096 个样本的平方曲线淡出，最后一个样本为零。
播放地址到达末尾后置完成标志，清零包络和 PCM，不再回绕。
切换时先用最多约 7.86 ms 释放旧音，再用约 1.97 ms 渐入；
没有自动轮换计时器，切换只由按键触发。

## 构建

Gowin EDA 打开 `Piano_88.gprj`，顶层为 `piano_88`，
运行综合、布局布线和码流生成。也可以在仓库根目录执行：

```powershell
& "D:\Gowin\Gowin_V1.9.12.03_x64\IDE\bin\gw_sh.exe" Piano_88/tools/build.tcl
```

构建脚本按自身路径定位工程，移动目录后不必修改绝对路径。
生成码流：`impl/pnr/Piano_88.fs`，使用 Gowin Programmer 下载。
源码及 `.gprj` 已包含生成的采样 ROM 和音区映射表，
不必联网或运行生成器即可构建。

## 仿真

```powershell
cd Piano_88/sim
vsim -c -do run.do
```

测试包括：KEY2 始终保持高电平的上电复位、上电静音、
第一次按下 A0、按键抖动与长按、88 音遍历及回绕、暂停 / 继续、
暂停中切换、复位重来，以及 PT8211 双声道位序、帧锁存和位时钟周期。
PCM 专项测试覆盖全部 88 音，各播放 32000 个样本，
与 Python 参考输出比对 880 个采样点，包括起音、插值和结束后的静音，
检查 ROM 地址界限、有效音频和无削波，并导出 A4 仿真波形。
全部 88 音检查结束后持续输出零，还检查了结束后的换音和重播。

若需重新下载原始录音（当前已包含）或生成采样 ROM 和试听文件：

```powershell
& .\Piano_88\tools\download_samples.ps1
& "C:\Users\30415\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" Piano_88/tools/generate_pcm_bank.py
& "C:\Users\30415\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" Piano_88/tools/verify_audio.py
```

生成器需要 Python 和 NumPy，本机使用随运行环境提供的 Python 3.12。
其他机器可使用安装了 NumPy 的 Python。`verify_audio.py` 在仿真后运行，
会生成 `output/piano_A4_rtl.wav` 和频谱核对报告。
本工程固定使用 50 MHz 系统时钟；改时钟时应同步调整音频 ROM、
启动计数、消抖计数和时序约束。
